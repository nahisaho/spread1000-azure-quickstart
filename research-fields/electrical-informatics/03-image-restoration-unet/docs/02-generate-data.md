# 02 — 合成データ生成

## なぜ合成データか

実データ (RAW 画像、磁気光学画像、超伝導線材の顕微鏡画像) は多くの場合:

- ライセンス・データ利用同意で配布に制約がある
- 装置ごとにフォーマット・ノイズ特性が違い、教材化に手間がかかる
- クリーン (ground truth) が本質的に存在しない (どれくらい復元できたか測れない)

本シナリオでは **完全に手続き的に生成した clean 画像** に **既知の Gaussian ノイズを加算** することで、`clean` と `noisy` のペアを豊富かつ再現可能に作ります。実データへの応用は [docs/07-ethics-and-limits.md](07-ethics-and-limits.md) と [docs/06-cleanup.md](06-cleanup.md) を参照してください。

## `generate_data.py` の動作

```bash
python src/generate_data.py --n-train 200 --n-val 40 --seed 42
```

主要オプション:

| オプション | 既定 | 説明 |
|---|---|---|
| `--n-train` | `200` | 学習サンプル数 |
| `--n-val` | `40` | 検証サンプル数 |
| `--size` | `128` | 画像サイズ (正方形、4 の倍数) |
| `--noise-sigma` | `0.10` | 加算 Gaussian ノイズの標準偏差 ([0,1] 正規化前提) |
| `--seed` | `42` | 完全再現用 |
| `--output-dir` | `<repo>/data` | 出力先 |

## 生成される画像

各サンプルは以下の要素をランダムに含む 128×128 の 1 チャネル画像です:

1. **背景グラデーション** (振幅 0.05〜0.20)
2. **矩形** (0〜5 個、強度 0.25〜1.0)
3. **円** (0〜5 個、半径 6〜22)
4. **アンチエイリアス直線** (0〜5 個)
5. **軽い Gaussian smoothing** (σ = 0.5〜1.2)

これに **σ = 0.10 の加算 Gaussian ノイズ** を加えます。ノイズ強度は SNR にして概ね 8〜15 dB 相当で、目視でも明らかにノイズがある状態です。

## 保存形式

```
data/
├── train/
│   ├── 0000.npz    # {"clean": (1,128,128) float32, "noisy": (1,128,128) float32}
│   ├── 0001.npz
│   └── ...
├── val/
│   ├── 0000.npz
│   └── ...
└── samples/
    └── preview.png    # 4 サンプルの clean/noisy 比較画像
```

`data/samples/preview.png` を開いて、生成された画像の見た目を確認してください。

## ノイズモデルの限界

Gaussian 加算ノイズは、次のような **実センサーノイズを完全にはモデル化しません**:

| 実ノイズ | 特性 | 本シナリオ |
|---|---|---|
| ショットノイズ (photon shot) | 信号強度に比例、Poisson 分布 | ✗ (簡単化のため定常 Gaussian) |
| リードノイズ | ISO/ゲイン依存の Gaussian | ○ 近似 |
| 固定パターンノイズ (FPN) | 空間的に一定 | ✗ |
| 量子化ノイズ | 一様分布 | ✗ |
| ホット/デッドピクセル | スパイク状 | ✗ |

より現実的なノイズを扱う場合は `add_gaussian_noise` を Poisson-Gaussian mixture などに置き換えて再学習してください（`generate_data.py:add_gaussian_noise` を差し替えるだけで済むように分離しています）。
