# 07 — 倫理と限界

> [!IMPORTANT]
> **本教材のモデルは教育・研究用の活動分類器です。医療機器ではありません。**
> 診断、治療方針の決定、患者監視、安全上重要な判断に **使用しないでください**。

## UCI HAR の適用範囲

このデータセットは以下に限定された条件で収集されています。

| 項目 | 条件 |
|---|---|
| 被験者 | 30 名、19〜48 歳、健康な成人 |
| 装着位置 | 腰 (Samsung Galaxy S II、単一機種) |
| センサー | 3 軸加速度 + 3 軸ジャイロ、50 Hz |
| 環境 | 実験室内、規定動作の実施 |
| 活動 | 6 種類の日常動作のみ |

したがって、高齢者・小児・患者集団、別装着位置、別機器、実生活の自由行動へはそのまま外挿できません。

## 被験者独立性の重要性

窓をランダム分割すると、被験者固有の癖や装着差が train / test に漏れ、精度は人工的に高くなります。本教材は **公式 subject-independent split** と、train 内での **subject-independent validation** を守ります。

## 生成 AI (LLM) との違い

本シナリオは 1D-CNN の教師あり学習で、E-1 の LLM LoRA と違い以下の懸念はありません。

- ハルシネーション
- プロンプトインジェクション

一方で、**Verbatim generative leakage differs from LLMs, but membership inference, model inversion, and memorization of outliers remain possible. / 逐語的な生成漏洩は LLM とは異なりますが、メンバーシップ推論・モデル反転・外れ値の記憶漏洩は依然として懸念されます。**

## 個人情報保護法 (APPI) と要配慮個人情報

医療・歩容・生体信号へ拡張する場合、日本の個人情報保護法 (APPI) を前提に扱ってください。

### 要配慮個人情報

次のような情報は **要配慮個人情報** に該当し得ます。

- 健康状態・診療歴・検査結果
- 生体認証に使える biometrics
- 障害の有無や状態

### 必要な管理策

- **明示的で十分な説明に基づく同意** を取る
- 取得時に **利用目的を特定** し、目的外利用を避ける
- **役割ベースのアクセス制御** と監査ログを残す
- 目的達成後は **保持期間を限定し削除** する
- **越境移転** は APPI 第24条を踏まえて受領者保護水準と同意要件を確認する
- **漏えい時対応** は速やかに開始し、72時間以内通知を目標に社内手順を整備する

## デュアルユース禁止リスト

独立した倫理審査・法務審査なしに、以下へ転用しないでください。

- [ ] 歩容監視・継続的な本人追跡
- [ ] 従業員監視・学生監視・出席監視
- [ ] 健康推定モデルの別目的再利用
- [ ] 医療判断・福祉判定・保険判定への直接利用
- [ ] 同意なく収集したセンサーデータの二次利用
- [ ] 高リスク集団に対する自動選別・スコアリング

## まとめ

- 本教材の目的は **1D-CNN による多チャネル時系列分類の学習**
- 医療・歩容・個人データへ拡張する場合は **APPI・倫理審査・契約条件** を追加で満たす必要がある
- 実務応用には **subject-/site-/device-/time-independent** 検証が必須
