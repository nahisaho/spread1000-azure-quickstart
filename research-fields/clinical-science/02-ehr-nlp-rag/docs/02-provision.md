# 02. Bicep でリソースをデプロイ

## デプロイ先リソース

- Azure OpenAI（`gpt-4o` + `text-embedding-3-large` の 2 デプロイメント付き）
- Azure AI Search（Basic SKU, semantic search 有効, SystemAssigned Identity 付き）
- Azure Blob Storage（`documents` コンテナー付き、Soft delete 7 日）
- Key Vault（RBAC モード）
- Log Analytics Workspace（AI Search・OpenAI の診断ログ送信先）

## 1. 環境変数の設定

```bash
cd research-fields/clinical-science/02-ehr-nlp-rag

# .env をコピーして編集
cp inputs/.env.example .env
$EDITOR .env    # LOCATION, RG, PI_TAG などを埋める

# .env を読み込み
set -a && source .env && set +a

# UNIQUE_SUFFIX が未設定またはプレースホルダー(REPLACE_ME_6HEX)なら自動生成して .env に書き戻す
if [[ -z "${UNIQUE_SUFFIX:-}" || "${UNIQUE_SUFFIX}" == "REPLACE_ME_6HEX" ]]; then
  export UNIQUE_SUFFIX=$(openssl rand -hex 3)
  # 既存の UNIQUE_SUFFIX 行を差し替え（無ければ追記）
  if grep -q '^UNIQUE_SUFFIX=' .env; then
    sed -i.bak "s|^UNIQUE_SUFFIX=.*|UNIQUE_SUFFIX=$UNIQUE_SUFFIX|" .env && rm -f .env.bak
  else
    echo "UNIQUE_SUFFIX=$UNIQUE_SUFFIX" >> .env
  fi
fi
echo "Using UNIQUE_SUFFIX=$UNIQUE_SUFFIX"
```

> [!TIP]
> `UNIQUE_SUFFIX` はリソース名のグローバル一意性を確保するための 3〜8 桁の 16 進数です。**一度生成したら固定**してください（再デプロイ時に変わると別リソースが作られてしまいます）。上記スニペットは初回のみ自動生成して `.env` に書き戻すため、2 回目以降は同じ値が使われます。

## 2. サブスクリプションとリージョン確認

```bash
az account show --query "{name:name, id:id, tenant:tenantId}" -o table
echo "Deploying to: $LOCATION"
```

> [!IMPORTANT]
> 本 quickstart は**合成データ動作確認専用**です。**実患者データ（PHI）は投入しないでください**（[01-prerequisites.md §6](01-prerequisites.md) 参照）。動作確認先として推奨リージョンは Japan East、次点で Sweden Central / East US 2（在庫がある場合）。

## 3. デプロイ前にモデルバージョン確認（**必須**）

`gpt-4o` の主要バージョンは次々と retirement されているため（`2024-08-06` は 2026-03-31 retired、`2024-11-20` は 2026-10-01 retire 予定）、**本テンプレートは Bicep デフォルトを廃止**し、`CHAT_MODEL_VERSION` を .env で明示指定することを要求します。以下で GA バージョンを確認してください:

```bash
# 対象リージョンで提供中の gpt-4o モデルバージョン一覧
az cognitiveservices model list --location "$LOCATION" \
  --query "[?kind=='OpenAI' && model.name=='gpt-4o'].{version:model.version, deprecation:model.deprecation}" \
  -o table

# ワンライナー: GA かつ 2026-12-31 以降まで残る最新版を取得
CHAT_MODEL_VERSION=$(az cognitiveservices model list -l "$LOCATION" \
  --query "[?model.name=='gpt-4o' && model.lifecycleStatus=='generallyAvailable' && (model.deprecation.inference==null || model.deprecation.inference > '2026-12-31')].model.version" \
  -o tsv | sort -r | head -1)
echo "$CHAT_MODEL_VERSION"   # 例: 2025-XX-XX
# → .env に CHAT_MODEL_VERSION=<出力値> を記載

# text-embedding-3-large も同様に確認 (Bicep デフォルトは '1')
az cognitiveservices model list --location "$LOCATION" \
  --query "[?kind=='OpenAI' && model.name=='text-embedding-3-large'].{version:model.version, deprecation:model.deprecation}" \
  -o table
```

`.env` の必須設定例:

```bash
# Chat model (REQUIRED — deploy.sh は未設定なら中断)
CHAT_MODEL_NAME=gpt-4o
CHAT_MODEL_VERSION=2025-XX-XX   # 上記コマンドの出力値

# Chat deployment name & その他は任意
# CHAT_DEPLOYMENT_NAME=gpt-4o
```

> [!WARNING]
> `EMBEDDING_MODEL_NAME` を `text-embedding-3-large` 以外に変更してはいけません。Bicep で作成される Search インデックスの vector 次元 (3072 固定) と埋め込みモデルの出力次元が一致しなくなり、`index_docs.py` の upload が失敗します。**本テンプレートは `text-embedding-3-large` (3072-dim) 専用**です。他のモデルを使いたい場合は `main.bicep` の Search index vector `dimensions` と `EMBEDDING_MODEL_NAME` を両方合わせて手動修正してください。

## 4. デプロイ実行

```bash
bash infra/deploy.sh
```

**所要時間**: 8〜12 分。以下の順で進行します:
1. リソースプロバイダー確認（30 秒）
2. リソースグループ作成（10 秒）
3. Bicep デプロイ（6〜10 分、OpenAI と AI Search が時間を要する）
4. RBAC 割り当て（1〜2 分）

## 5. デプロイ完了確認

デプロイ完了時に出力される JSON を控えてください:

```json
{
  "documentsContainerName": { "value": "documents" },
  "openAiEndpoint": { "value": "https://oai-ehr-nlp-<suffix>.openai.azure.com/" },
  "openAiName": { "value": "oai-ehr-nlp-<suffix>" },
  "searchEndpoint": { "value": "https://srch-ehr-nlp-<suffix>.search.windows.net" },
  "searchName": { "value": "srch-ehr-nlp-<suffix>" },
  "storageAccountName": { "value": "stehrnlp<suffix>" },
  ...
}
```

これらは `03-index-documents.md` と `04-query-rag.md` のスクリプトが参照します。**次のコマンドで `.env` に追記**します（`deploy.sh` が書き出した `.last-deployment-name` を利用して、同じリソースグループで再デプロイした場合でも最新の値を取得します）:

```bash
DEPLOYMENT_NAME=$(cat infra/../.last-deployment-name)
echo "Reading outputs from deployment: $DEPLOYMENT_NAME"

{
  echo ""
  echo "# Auto-generated by 02-provision.md"
  echo "OPENAI_ENDPOINT=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.openAiEndpoint.value -o tsv)"
  echo "OPENAI_NAME=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.openAiName.value -o tsv)"
  echo "SEARCH_ENDPOINT=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.searchEndpoint.value -o tsv)"
  echo "SEARCH_NAME=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.searchName.value -o tsv)"
  echo "STORAGE_ACCOUNT=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.storageAccountName.value -o tsv)"
  echo "DOCS_CONTAINER=documents"
  echo "OPENAI_GPT_DEPLOYMENT=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.chatDeploymentName.value -o tsv)"
  echo "OPENAI_EMBED_DEPLOYMENT=$(az deployment group show -g "$RG" -n "$DEPLOYMENT_NAME" --query properties.outputs.embeddingDeploymentName.value -o tsv)"
  echo "SEARCH_INDEX=ehr-notes"
} >> .env

set -a && source .env && set +a
```

## 6. トラブルシューティング

| 症状 | 原因・対応 |
|---|---|
| `SkuNotAvailable` (Azure OpenAI) | 対象リージョンで `gpt-4o` が未提供。`--location` を Sweden Central に変更、または [`../../../../docs/02-gpu-quota.md`](../../../../docs/02-gpu-quota.md) 参考に別リージョンを試す |
| `InvalidTemplateDeployment: The subscription is not registered to use...` | `Microsoft.CognitiveServices` / `Microsoft.Search` 未登録 → `deploy.sh` 冒頭で自動登録。手動なら `az provider register --namespace Microsoft.CognitiveServices --wait` |
| `Conflict: Model gpt-4o is unavailable in ...` | 選択したリージョンで `gpt-4o` の指定バージョンが提供されていない → §3 の `az cognitiveservices model list` で GA バージョンを再取得し `.env` の `CHAT_MODEL_VERSION` を更新、または `deployGpt4o=false` にしてデプロイ後手動でモデルを選ぶ |
| `AuthorizationFailed` on role assignment | 呼び出し元に `User Access Administrator` が無い → 機関管理者に付与依頼 |
| `Quota Exceeded: Cognitive Service tokens per minute` | TPM quota 不足 → Azure Portal → Azure OpenAI → Quotas から申請 |
