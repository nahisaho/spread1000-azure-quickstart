# Dependency Lock File Instructions

This directory holds platform-specific lock files generated by
[pip-tools](https://github.com/jazzband/pip-tools).

## Regenerating the lock file

```bash
# 1. Install pip-tools
pip install pip-tools

# 2. Install PyTorch CPU wheel first (not on PyPI)
pip install torch==2.7.1 torchvision==0.22.1 \
    --index-url https://download.pytorch.org/whl/cpu

# 3. Compile with hashes
pip-compile ../requirements.in \
    --generate-hashes \
    --output-file requirements.txt
```

The resulting `requirements.txt` can be installed with hash verification:

```bash
pip install -r requirements-lock/requirements.txt --require-hashes
```

## Notes

- Lock files are **platform-specific** (Python version, OS, CPU arch).
- Re-run `pip-compile` whenever `requirements.in` changes or you upgrade
  a dependency.
- `torch` and `torchvision` are deliberately excluded from the lock file
  because they require a separate index URL (`--index-url`). Pin them
  explicitly in your CI or `Dockerfile`.
