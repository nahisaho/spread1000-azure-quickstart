# 07 — 倫理と限界

## 資料の著作権と利用許諾

- 江戸期以前の古文書は原本自体は著作権消滅
- ただし **翻刻書、活字化された二次資料** には翻刻者の編集著作権が発生しうる
- **画像の複製権**: 所蔵館が撮影費・掲載許諾料を求めることが多い
- 公開時は所蔵館の許諾確認必須

## LLM 出力の学術的信頼性

- LLM の抽出結果は **仮説** であり、必ず史料原本と付き合わせる
- 特に人物名・年号・地名は Hallucination 発生率が高い
- 論文に載せる場合: 「Document Intelligence + gpt-4o-mini による自動抽出、著者検証済み」と方法欄に明記

## 学術データベースへの登録

- 抽出結果を DB に登録する際は、抽出方法・モデル・日付・検証者を Provenance として必ず記録
- CH (人文科学とコンピュータ) 研究会等の標準に準拠

## クラウド送信の制約

- **未公開資料**をクラウドに送るのは所蔵館の許諾が必要な場合がある
- Azure OpenAI は **顧客データを学習に使用しない** (契約書に明記) が、
  組織のデータガバナンス方針を確認
- 高機密資料は on-premise OCR (Tesseract + Layout Parser 等) 検討

## デジタル人文学の批判的視点

- AI 翻刻の効率化と引き換えに **筆写・翻刻を通じた深い読解**が失われる懸念
- 学生教育: AI 翻刻を最終回答としない、必ず人間の読み下しを経ることを推奨
- 「精度何%」の議論は資料の**歴史的意義**を測る指標にはならない
