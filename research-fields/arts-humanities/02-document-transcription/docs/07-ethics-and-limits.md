# 07 — 倫理と限界

## 資料の著作権と利用許諾

- 江戸期以前の古文書は原本自体は著作権消滅
- ただし **翻刻書、活字化された二次資料** には翻刻者の編集著作権が発生しうる
- **画像の複製権**: 所蔵館が撮影費・掲載許諾料を求めることが多い
- 公開時は所蔵館の許諾確認必須

## 資料所有権・寄贈条件・コミュニティの同意

- **所有権と Deed of Gift**: 所蔵館への寄贈条件 (Deed of Gift) が AI 処理・クラウド送信を
  禁止または制限している場合があります。資料受け入れ時の条件を必ず確認してください。
- **子孫・コミュニティの同意**: 個人文書・地域文書について、子孫・関係コミュニティへの
  事前説明と同意取得を推奨します。
- **先住民族・マイノリティコミュニティ資料**: TK ラベル (Traditional Knowledge Labels)
  や BC ラベル (Biocultural Labels) が付与されている資料は、アクセス・複製・
  デジタル化・AI 処理に制約があります。https://localcontexts.org/ を参照してください。
- **神聖・文化的に制限された資料**: 宗教儀礼・秘伝・祭祀に関わる資料は
  OCR・AI 解析の前に文化的な判断が必要です。
- **私信・日記の盗聴リスク**: 個人の私的通信をクラウド API に送ることは、
  当事者・遺族のプライバシー侵害につながりうることを認識してください。

## デュアルユース・監視リスク

- 自動翻刻・人物特定機能は、反体制的な活動家・少数派コミュニティのメンバーを
  特定・監視するために転用されうる潜在的なリスクがあります。
- 研究目的を明確にし、データアクセスを最小化・制限してください。

## Azure OpenAI データ処理ポリシー

- Azure OpenAI はデフォルトで **abuse monitoring のため 30 日間入力データを保持** します。
  オプトアウトが必要な場合は Microsoft との契約上の申請が必要です。
- **データ所在地 (Data Residency)**: AOAI デプロイメントのリージョンを選択してください。
  Global デプロイメントは複数リージョンをまたいで処理され、DataZone デプロイメントは
  地理的範囲が限定されます。研究機関の DPA・データガバナンスポリシーと照合してください。
- Azure OpenAI は **顧客データをモデル学習に使用しない** (契約書に明記) が、
  組織のデータガバナンス方針を確認してください。

## LLM 出力の学術的信頼性

- LLM の抽出結果は **仮説** であり、必ず史料原本と付き合わせる
- 特に人物名・年号・地名は Hallucination 発生率が高い
- 論文に載せる場合: 「Document Intelligence + gpt-4o-mini による自動抽出、著者検証済み」と方法欄に明記

## 学術データベースへの登録

- 抽出結果を DB に登録する際は、抽出方法・モデル・日付・検証者を Provenance として必ず記録
- `outputs/manifest.json` の内容 (SHA-256, API バージョン, タイムスタンプ) を活用してください
- CH (人文科学とコンピュータ) 研究会等の標準に準拠

## デジタル人文学の批判的視点

- AI 翻刻の効率化と引き換えに **筆写・翻刻を通じた深い読解**が失われる懸念
- 学生教育: AI 翻刻を最終回答としない、必ず人間の読み下しを経ることを推奨
- 「精度何%」の議論は資料の**歴史的意義**を測る指標にはならない
