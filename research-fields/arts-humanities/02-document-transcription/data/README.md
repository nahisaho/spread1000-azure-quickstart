# データ

古文書 PDF/画像は各自で用意してください。

## 公開データ (パブリックドメイン)

- **国立国会図書館デジタルコレクション**: https://dl.ndl.go.jp/
  - 江戸期出版物、明治期公文書等が PDF ダウンロード可能
- **国立公文書館デジタルアーカイブ**: https://www.digital.archives.go.jp/
  - 内閣文庫、太政官記録等
- **東京大学史料編纂所**: https://www.hi.u-tokyo.ac.jp/
  - 大日本史料、大日本古文書のスキャン

## サンプル用途 (テスト向け)

Wikipedia 日本語版から歴史文書の画像 (CC-BY-SA) を保存してテストに使えます:
- 例: 「大宝律令」「五箇条の御誓文」等の項目画像

抽出結果は `outputs/` に保存されます (gitignore 済み)。
