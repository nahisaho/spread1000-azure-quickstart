# データ

古文書 PDF/画像は各自で用意してください。

## 候補となる公開ソース (要検証)

**注意**: 各アイテムのライセンス・帰属義務・肖像権・組織ポリシーは個別に確認してください。
「パブリックドメイン」を一律に宣言せず、以下を必ず記録してください:

- Rights statement (RightsStatements.org, CC ライセンス, PDM, 権利不明 など)
- 出典 URL とアクセス日
- 帰属表示 (Attribution) 義務の有無
- フォント/画像/写真が独立したライセンスを持つ場合はその内容
- 再配布・商用利用の可否

| ソース | URL | 備考 |
|---|---|---|
| 国立国会図書館デジタルコレクション | https://dl.ndl.go.jp/ | 江戸期出版物・明治期公文書等。個別アイテムのライセンス表示を確認 |
| 国立公文書館デジタルアーカイブ | https://www.digital.archives.go.jp/ | 内閣文庫・太政官記録等。利用規約を確認 |
| 東京大学史料編纂所 | https://www.hi.u-tokyo.ac.jp/ | 大日本史料・大日本古文書。二次利用前に問い合わせ |

## サンプル用途 (テスト向け)

Wikipedia 日本語版から歴史文書の画像 (CC-BY-SA 4.0) を保存してテストに使えます。
**CC-BY-SA は帰属表示と同一ライセンスでの再配布が必要**です。

- 例: 「大宝律令」「五箇条の御誓文」等の項目画像

抽出結果は `outputs/` に保存されます (gitignore 済み)。
