# 材料・プロセス・応用医工学

SPReAD-1000 第 1 回公募（令和 8 年度）**材料・プロセス・応用医工学** 分野（採択 33 課題）向けの Azure クイックスタート集です。

## 想定ワークロード

採択課題の内訳から、以下の 3 系統がカバー対象になります。

| 系統 | 対象研究例（採択課題より） | 対応シナリオ |
|---|---|---|
| **材料物性の機械学習予測** | バンドギャップ・形成エネルギー・弾性など、DFT データからの回帰・分類 | 01 |
| **ニューラルネットワークポテンシャル (NNP)** | 分子動力学・第一原理計算の代替（MACE-MP-0 等の基盤モデル） | 02 (準備中) |
| **顕微鏡画像解析** | SEM/STEM/光学顕微鏡の欠陥・粒界・組織セグメンテーション | 03 (準備中) |

## シナリオ一覧

| # | シナリオ | 手法 | 実行環境 | コスト目安 |
|---:|---|---|---|---:|
| 01 | [材料バンドギャップ回帰](01-materials-property-prediction/) | Materials Project API + Matminer (magpie 132-d) + XGBoost、reduced-formula GroupKFold | ローカル / WSL2 (Python 3.12) | ~$0（ローカル） |
| 02 | [MACE-MP-0 汎用 NNP](02-nnp-mace-mp/) | MACE-MPA-0 (MIT) で構造緩和 + Langevin NVT-MD、任意で Azure ML T4 GPU | ローカル (CPU) / AML T4 (任意) | ~$0（ローカル）/ ~$0.5（T4） |
| 03 | 顕微鏡画像セグメンテーション（準備中） | U-Net で合成 SEM/STEM 粒界・欠陥検出 | AML GPU (T4) | ~$1–2 |

## 進め方

初心者は **01 → 02 → 03** の順で進めることを推奨します。01 は課金 0 円でローカル実行できるので、Azure の準備を待たずに機械学習パイプライン（データ取得 → 特徴量化 → 学習 → 評価）を一通り体験できます。02 以降で AML GPU に進みます。

## 共通の注意点

- **Materials Project ライセンス**: コア DB は CC BY 4.0 ですが、**GNoME 由来データは CC BY-NC** です。教育・商用配布時は明示的に `include_gnome=False` を渡してください（各シナリオでコード化済み）。
- **DFT バンドギャップの系統誤差**: PBE/GGA は実験値より 0.5–1.5 eV 過小評価します。実験値との比較には HSE/G0W0 再計算が必要です。
- **Python バージョン**: matminer 系は Python 3.12 まで対応（3.13 は未対応）。
